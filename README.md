# 🏥 Healthcare Data Analytics Project (SQL + Python + Power BI)

## 📌 Project Overview
This project provides an end-to-end data analysis solution for healthcare data. It covers data extraction, cleaning using Python, and an interactive Power BI dashboard to analyze patient count, revenue, medical conditions, and insurance provider performance.

## 🛠️ Tech Stack & Tools Used
* **SQL:** Initial data exploration and queries.
* **Python (Pandas):** Data cleaning, formatting, and handling missing values.
* **Power BI:** Data visualization, KPI tracking, and interactive dashboard creation.

## 📊 Dashboard Key Metrics (KPIs) & Insights
* **Total Patients:** 55.5K
* **Total Revenue:** $1.42 Billion
* **Gender Distribution:** Balanced split between Male (27.73K) and Female (27.77K) patients.
* **Medical Condition Analysis:** Revenue breakdown across various health conditions.
* **Insurance Providers:** Performance tracking across major insurance carriers.
